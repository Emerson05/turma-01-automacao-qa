# 🧪 Automação QA

Projeto desenvolvido para estudos e prática de **automação de testes e programação com TypeScript**, utilizando Node.js.

O projeto tem como objetivo praticar conceitos de programação, execução de scripts e fundamentos relacionados à automação e testes de software.

## 🚀 Tecnologias utilizadas

* **TypeScript**
* **Node.js**
* **tsx**
* **prompt-sync**
* **npm**

O projeto utiliza TypeScript com configurações mais rigorosas, incluindo `strict`, `isolatedModules` e `noUnusedParameters`.

## ⚙️ Pré-requisitos

Antes de começar, você precisa ter instalado:

* [Node.js](https://nodejs.org/)
* npm

O projeto utiliza ferramentas que requerem **Node.js 18 ou superior**.

## 📥 Instalação

Clone o repositório:

```bash
git clone <URL-DO-REPOSITORIO>
```

Entre na pasta:

```bash
cd automacao-qa
```

Instale as dependências:

```bash
npm install
```

## ▶️ Executando o projeto

Para executar o ambiente de desenvolvimento:

```bash
npm run dev
```

Esse comando realiza primeiro a verificação de tipos do TypeScript e depois executa o arquivo relacionado à aula 26.

## 🔍 Verificação de tipos

Para verificar possíveis erros de TypeScript sem gerar os arquivos compilados:

```bash
npm run type-check
```

## 🏗️ Build

Para compilar o projeto:

```bash
npm run build
```

Os arquivos compilados são direcionados para a pasta `dist`.

## ▶️ Executar versão compilada

Após realizar o build:

```bash
npm start
```
